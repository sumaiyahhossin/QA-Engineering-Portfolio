Test Scenarios

Project Name: Healthcare Plan Browsing and Public Account Access
Company: Humana

Scenario 1: Verify public plan finder page loads
Expected Result: The public plan finder page loads and displays its search input.

Scenario 2: Verify ZIP code can be entered
Expected Result: The search field accepts the test ZIP code and displays the entered value.

Scenario 3: Verify plan search submission
Expected Result: Submitting a valid ZIP code starts the plan search workflow.

Scenario 4: Verify public plan results
Expected Result: Public plan results or a clear page-level response are displayed, subject to site availability.

Scenario 5: Verify public plan details navigation
Expected Result: Selecting an available plan details action opens the related public plan information.

Scenario 6: Verify account sign-in page loads
Expected Result: The sign-in page and username field are displayed.

Scenario 7: Verify invalid login handling
Expected Result: Incorrect credentials are rejected and an appropriate error or validation response is shown.

Scenario 8: Verify blank login submission
Expected Result: Required fields are identified and submission is prevented or a validation response is shown.

Scenario 9: Verify test account advances to the next account step
Expected Result: If test credentials are accepted, the flow advances to the next account setup or sign-in step. This does not mean member coverage or Medicare access was verified.

Scenario 10: Verify regression after a website update
Expected Result: Existing public plan browsing and sign-in page behaviors continue to work.

Scope note: These scenarios do not cover Medicare eligibility, enrollment, or private member coverage. Public website behavior can change.
