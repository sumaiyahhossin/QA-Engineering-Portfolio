Selenium Test Scripts

Project: Healthcare Plan Browsing and Member Coverage

Company: Humana

This folder contains Java Selenium WebDriver automation test scripts organized by test scenario.

Test Scripts

1. Test01_LoginTest.java
   Validates the application login workflow.

2. Test02_InvalidLoginTest.java
   Validates application behavior when invalid login credentials are entered.

3. Test03_PlanSearchTest.java
   Validates healthcare plan search functionality.

4. Test04_PlanDetailsTest.java
   Validates healthcare plan details displayed to the user.

Framework and Tools

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA

Test execution and results should be documented after running the scripts.
