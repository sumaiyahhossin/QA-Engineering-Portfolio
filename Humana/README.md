Humana QA Project

Healthcare Plan Browsing and Public Account Access

This section showcases QA documentation, manual testing, Selenium automation, SQL validation examples, defect report templates, and test execution tracking for public healthcare plan browsing and account sign-in workflows.

Testing Scope

- Public healthcare plan browsing
- ZIP code search and public plan details
- Account sign-in page behavior
- Invalid input and required field validation
- Application navigation

The public plan finder is not a Medicare eligibility or member coverage test. The account used for sign-in practice is not fully set up, and the portfolio does not claim access to private member information.
