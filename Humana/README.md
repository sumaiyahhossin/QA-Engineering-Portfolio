## Portfolio & Data Notes

- **Independent Portfolio Work:** The test scripts, SQL queries, manual test cases, and documentation in this repository are independent practice examples created to showcase my technical skills. They are separate from my workplace code and do not contain proprietary software, internal test suites, or confidential details from Humana or Healthfirst.
- **Experience Summaries:** The experience entries describe my actual employment history and responsibilities on the job, while the public files in this repository serve as an independent demonstration of those capabilities.
- **Synthetic Data & Local Execution:** Automated Selenium tests run against local test pages using synthetic test values (`MEM-SYN-xxxx`). The GitHub Actions pipeline executes in an isolated environment without connecting to internal enterprise servers or accessing real member data.
