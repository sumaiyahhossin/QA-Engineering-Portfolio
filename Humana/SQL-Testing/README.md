# SQL Testing

This folder contains SQL examples for data validation related to member and coverage workflows.

[View the five SQL queries and expected results](SQL-QUERIES.md).

## Queries Included

- Find a member test record and check its status.
- Review coverage records and their effective dates.
- Look for duplicate active coverage records.
- Find coverage dates that don't make sense.
- Join member and coverage records to check how they relate.

## Tools and SQL

The examples use Oracle SQL syntax and cover SELECT, WHERE, INNER JOIN, GROUP BY, HAVING, COUNT, NULL checks, and date comparisons.

The public examples use generic table and column names with synthetic IDs. They demonstrate read-only data checks and are not queries against Humana systems or production data.
