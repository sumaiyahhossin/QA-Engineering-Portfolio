## Preconditions

1. QA Staging environment (`qa-medicare.humana.com`) is operational.
2. Synthetic test data is ready: Queens, NY ZIP code (`11417`).
3. Desktop browser viewport is set to `1920x1080`.

## Steps to Reproduce

1. Navigate to `/medicare/medicare-advantage-plans`.
2. Verify the **"Let us help you choose a plan"** guidance wizard header renders.
3. In the postal code field (`input[autocomplete='postal-code']`), enter ZIP `11417`.
4. Click **"Get Started"** (`button[data-search-button]`).
5. Select **"Medicare Advantage (Part C)"**.
6. Click **"View Plan Match"**.

## Expected Result

The plan-matching workflow processes the payload within the documented threshold (less than 3.0 seconds) and displays the results page with the heading **"Your plan matches"** alongside regional Medicare Advantage cards.

## Actual Result

Upon clicking **"View Plan Match"**, the UI enters an unhandled loading state and the results container never renders:

- The automated Selenium script throws a `TimeoutException` after a 20-second explicit wait on element visibility (`plan-card-results`).
- DevTools shows an **HTTP 504 Gateway Timeout** on the backend AJAX endpoint: `POST /api/v2/plan-match`.
- Shadow DOM component `nc-dropdown-menu` fails to unpack child nodes due to the unhandled API timeout response.
