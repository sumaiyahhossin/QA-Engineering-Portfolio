Manual Testing

Project: Healthcare Plan Browsing and Public Account Access

This section contains manual testing documentation for public plan browsing, plan details, application navigation, form validation, and account sign-in workflows.

Contents

- TEST_CASES.md – manual test scenarios, preconditions, steps, and expected results
- TEST_EXECUTION_RESULTS.md – execution tracking for the documented test cases
- Humana_Manual_Test_Cases.xlsx – spreadsheet version of the manual test cases
- Defect-Reports/ – defect report template

Test Execution

Record the environment, page or build version, test data reference, date, actual result, and status when a test is run. Do not mark a test as Passed without checking the actual result.

Scope

Public plan browsing does not verify Medicare eligibility or private member coverage. Do not include member personal information or account details in this public repository.
