Manual Testing

Project: Healthcare Plan Browsing and Member Coverage

This section contains manual testing documentation for healthcare plan browsing, plan details, application navigation, form validation, and member coverage workflows.

Contents

- TEST_CASES.md – manual test scenarios, preconditions, steps, and expected results
- TEST_EXECUTION_RESULTS.md – execution tracking for the documented test cases
- Humana_Manual_Test_Cases.xlsx – spreadsheet version of the manual test cases
- Defect-Reports/ – defect report format and sample portfolio scenario

Record the environment, build, test data reference, date, actual result, and status when a test is run. Do not mark a test as Passed without checking the actual result.

The included test cases are portfolio examples. Keep employer-specific details and member data private.
