QA Concepts

Verification vs Validation
Verification checks whether work products meet specified requirements. Validation checks whether the delivered product meets user needs.

Positive vs Negative Testing
Positive testing checks expected valid inputs. Negative testing checks invalid, missing, or unexpected inputs and the system's response.

Retesting vs Regression
Retesting checks whether a specific defect has been fixed. Regression testing checks whether a change caused problems in other existing functionality.

Test Data
Test data should cover valid, invalid, missing, and boundary conditions. Use synthetic or approved non-production records.

Risk-Based Testing
Prioritize testing based on the likelihood and impact of failure. Critical user journeys, sensitive data handling, and high-impact business rules often need stronger coverage.

Traceability
A requirements traceability matrix maps requirements to test scenarios, test cases, and execution results so coverage can be reviewed.
