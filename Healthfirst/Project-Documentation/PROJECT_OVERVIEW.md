# Member Portal & Healthcare Workflows QA

**Company:** Healthfirst  
**Role:** Quality Assurance  
**Project area:** Member-facing healthcare applications  
**Methodology:** Agile / Scrum

## Project Overview

My testing work focused on member-facing healthcare workflows, including eligibility checks, health plan browsing and selection, form validation, and the information shown to members. I checked that workflows behaved as expected, errors were handled clearly, and displayed values matched the test data.

## My Responsibilities

- Reviewed requirements and identified test scenarios.
- Created and executed manual test cases covering positive, negative, and boundary conditions.
- Checked eligibility results, coverage information, plan search, and selection workflows.
- Tested form validation, navigation, and error messages.
- Automated repeatable UI checks using Playwright and Cypress.
- Checked API requests, responses, and error handling with Postman.
- Validated application data and recorded defects for follow-up.
- Retested fixes and performed regression checks.

## Main Testing Areas

### Member Eligibility and Coverage
- Checked valid, invalid, and missing member information.
- Reviewed eligibility status and coverage dates.
- Checked unsuccessful service responses and error messages.

### Plan Search and Selection
- Tested plan searches and ZIP code validation.
- Reviewed plan listings, details, and comparison behavior.
- Checked selection and enrollment-form validation.

### API and Data Checks
- Checked response status codes, required fields, and error handling.
- Compared displayed values with expected test data.

### Regression Testing
- Rechecked affected workflows after changes and defect fixes.
- Used repeatable browser tests for selected member and plan workflows.

## Portfolio Materials

The related folders contain manual test cases, defect documentation, UI automation, API tests, and data validation examples. Public automation runs against local demo applications and synthetic test data, not Healthfirst internal systems. No employer source code, private endpoints, or member information is included.
