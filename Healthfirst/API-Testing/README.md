API Testing

This section covers REST API testing concepts relevant to member-facing healthcare workflows.

Testing Areas
- Request method and endpoint validation
- HTTP status code validation
- Response body and JSON structure
- Required and optional fields
- Data types and field formats
- Positive and negative scenarios
- Error handling
- Response time observations
- Data consistency between API and UI

Postman Workflow
1. Select the approved environment.
2. Use an authorized endpoint and test account.
3. Set required headers and request parameters.
4. Send the request.
5. Validate the status code and response body.
6. Add assertions for documented requirements.
7. Save sanitized examples only.

No internal API endpoints, tokens, request payloads, or production data are included in this public portfolio.
