# Healthfirst QA Portfolio

This section covers QA work related to member-facing healthcare applications, with a focus on eligibility workflows and health plan selection.

## Testing Areas

- Member-facing workflow and navigation
- Eligibility-related validation
- Health plan browsing and selection
- Manual and regression testing
- UI automation with Playwright and Cypress
- API checks with Postman
- SQL and application data validation
- Defect tracking and retesting
