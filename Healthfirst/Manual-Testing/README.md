# Manual Testing

This section brings together manual QA documentation for member-facing healthcare workflows, eligibility validation, health plan browsing, and defect tracking. The public portfolio materials use generalized scenarios and synthetic data.

## Files

- [Excel workbook](Healthfirst_Manual_Test_Cases.xlsx) with case details, recorded outcomes, and the defect log.
- [Manual test cases](TEST_CASES.md): Detailed records for all 50 test cases and QA activities, including steps, expected and recorded actual results, statuses, dates, environments, and defect references.
- [Test execution results](TEST_EXECUTION_RESULTS.md): A concise summary of 50 recorded QA cases and activities: 48 Passed and 2 Failed, with testing-area totals and failed-case references.
- [Defect reports](Defect-Reports/README.md): Defect documentation guidance and a [reusable defect report template](Defect-Reports/DEFECT-REPORT-TEMPLATE.md).

## Test documentation

The 50 documented QA entries include steps, expected results, recorded actual results, execution dates, environments, and defect references. The execution summary shows 48 Passed and 2 Failed. These are recorded results, not independently rerun tests. Where detailed observations were not documented, no additional behavior has been assumed.

The public examples use synthetic data and exclude member information, credentials, private system addresses, and confidential employer records.

The Agile QA section also documents process and collaboration activities. Those entries should not be interpreted as 10 additional automated or independently verified functional tests.
