# Manual Testing

This section brings together manual QA documentation for member-facing healthcare workflows, eligibility validation, health plan browsing, and defect tracking. The public portfolio materials use generalized scenarios and synthetic data.

## Files

- [Manual test cases](TEST_CASES.md): Detailed tables for all 50 test cases, including steps, expected and recorded actual results, statuses, dates, environments, and defect references.
- [Test execution results](TEST_EXECUTION_RESULTS.md): A 50-row summary of the recorded manual execution results: 48 Passed and 2 Failed, including dates, environments, and defect references.
- [Defect reports](Defect-Reports/README.md): Defect documentation guidance and a [reusable defect report template](Defect-Reports/DEFECT-REPORT-TEMPLATE.md).

## Test documentation

The 50 manual test cases include steps, expected results, recorded actual results, execution dates, environments, and defect references. The execution summary shows 48 Passed and 2 Failed. These are recorded results, not independently rerun tests. Where detailed observations were not documented, no additional behavior has been assumed.

The public examples use synthetic data and exclude member information, credentials, private system addresses, and confidential employer records.
