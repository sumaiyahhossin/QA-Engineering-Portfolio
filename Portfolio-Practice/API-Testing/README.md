API Testing Practice – Postman Echo

This is an independent API testing exercise using the public Postman Echo service. It is not a Healthfirst or Humana API.

Coverage
- GET request and query parameter validation
- POST request and JSON body validation
- Response status and structure
- Header validation
- Response time observation

Import
Import Postman-Echo-API-Tests.postman_collection.json into Postman and run the collection against the public Postman Echo service.

No API key or employer credentials are required. Public service availability may change.
